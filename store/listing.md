デベロッパー ダッシュボードの各欄に、下の文をそのままコピーして貼る。名前と短い説明は zip 内の manifest から自動で入る。

## 名前 (manifest から自動)

Better Sakugabooru

## 短い説明 (manifest から自動)

Sakugabooru を日本語で。タグの日本語表示・日本語検索・見やすい一覧。

## 説明 (「ストアの掲載情報」タブ)

Sakugabooru (sakugabooru.com) を日本語で見やすくする拡張機能です。作画アニメーションが好きな人のための非公式ツールで、Sakugabooru の運営とは関係ありません。

■ 一覧ページ
・作画者・作品・技法のタグを日本語で表示します。原文 (ローマ字) も小さく添えます。辞書に無いタグは「未訳」の印を付けて原文のまま出します
・左の欄に、いま表示している投稿の作画者・作品・技法を件数順にまとめます。名前にマウスを乗せると、その人のカードが強調されます
・カードの作品名や技法タグを押すと、そのタグの一覧に移ります
・1 ページの件数を 24 / 40 / 60 / 100 から選べます
・サムネにマウスを乗せると無音で再生します
・検索欄に「金田」「かなだ」のように日本語やかなで打つと、英語のタグを提案します

■ 詳細ページ
・動画と操作列が 1 画面に収まるように大きさを合わせます。題名と前後の投稿ボタンは右の列にまとめます
・独自の操作列: 再生速度 (サイトの設定どおり)、1 コマ送り / 戻し、コマ番号、ループ、mp4 の保存、全画面
・作画者ごとに「作画wiki」ボタンがあり、作画@wiki の該当ページを開きます
・プールに入っている投稿は、右の列からプール内の前後へ移れます

■ そのほか
・ライト / ダークのテーマ (OS に合わせる、または手動)
・トップページを開くと新着一覧へ移動 (設定で OFF にできます)
・ツールバーのアイコンから、機能ごとの ON / OFF や表示件数を変えられます

■ 辞書について
タグの日本語訳は、公開している GitHub リポジトリ (https://github.com/HTPK/better-sakugabooru) の辞書データです。拡張機能が 1 日 1 回取得するので、訳の追加や修正は拡張機能の更新を待たずに届きます。未訳のタグにある「訳を提案する」から提案を送れます。

■ プライバシー
個人情報や閲覧履歴を集めることはありません。詳しくは https://github.com/HTPK/better-sakugabooru/blob/main/PRIVACY.md をご覧ください。

## プライバシーへの取り組み (「プライバシー」タブ)

### 単一用途の説明

Sakugabooru (sakugabooru.com) のページを日本語で読みやすく表示すること。タグの日本語表示、日本語での検索補完、一覧と詳細ページの表示の改善を行います。

### 権限が必要な理由

| 権限 | 貼る文 |
|---|---|
| `storage` | 利用者の設定と、取得したタグ辞書のキャッシュを保存するために使います。 |
| `alarms` | タグ辞書を 1 日 1 回自動で更新するために使います。 |
| ホスト権限 `https://www.sakugabooru.com/*` | sakugabooru.com のページの表示を書き換えるために使います。他のサイトにはアクセスしません。 |

### リモートコード

「いいえ、リモートコードを使用していません」を選ぶ。

補足 (審査メモ欄があれば): すべての JavaScript は zip に含まれています。jsDelivr から取得する辞書は JSON データで、コードとして実行しません。
