# Chrome Web Store 掲載内容

Web Store の開発者ダッシュボードの各欄に、下の文をそのままコピーして貼る。

## タイトル

Better Sakugabooru — 日本語化と見やすい一覧

## 短い説明 (132 字以内)

Sakugabooru のタグを日本語で表示し、一覧を見やすく。作画者・作品・技法の日本語表示、日本語検索、ホバー再生、ダークテーマに対応。

## 詳細説明

Sakugabooru (sakugabooru.com) を日本語で見やすくする拡張機能です。作画アニメーション好きのための、非公式の表示改善ツールです。

【機能】
- 日本語タグ表示: 作画者・作品・技法のタグを日本語で表示。原文 (ローマ字) も小さく添えられます。辞書に無いタグは「未訳」マーク付きで原文のまま表示
- 密な一覧: 1 ページ 24 / 40 / 60 / 100 件から選べるグリッド。サムネの下に作品名・作画者・点数と投稿日・技法タグを表示 (各項目は設定で ON/OFF)
- ホバー再生: サムネにマウスを乗せると無音で再生
- 日本語・かな検索補完: 「金田」「かなだ」と打つと英語タグを提案
- 詳細ページ: タイトル帯と、作画者 / 作品 / 技法に整理されたサイドバー
- ライト / ダーク: OS に合わせる、または手動で切替
- トップページを新着一覧に: sakugabooru.com を開くと投稿一覧へ (設定で OFF 可)
- 設定ポップアップ: ツールバーのアイコンから、機能ごとの ON/OFF や表示件数を変更

【辞書について】
タグの日本語訳は、公開 GitHub リポジトリ「better-sakugabooru」の dict フォルダにある JSON データです。拡張機能が 1 日 1 回取得します。辞書の網羅率は順次向上中です。未訳タグの「訳を提案する」から改善提案を送れます。

【プライバシー】
個人情報の収集・送信は一切ありません。詳しくは「プライバシー」欄を参照してください。

## 権限の理由

| 権限 | 理由 |
|---|---|
| `storage` | 設定と、取得した辞書のキャッシュを保存するため |
| `alarms` | 辞書を毎日 1 回更新するため |
| `https://www.sakugabooru.com/*` (ホスト権限) | Sakugabooru のページの表示を書き換えるため。他のサイトには一切アクセスしません |

## プライバシー文

この拡張機能は、利用者の個人情報・閲覧履歴・操作内容を収集せず、開発者のサーバーにも送信しません。設定は利用者のブラウザ内 (Chrome 同期ストレージ) にのみ保存されます。

外部との通信は次の 3 点だけです。

1. 辞書データの取得: タグの日本語訳 (JSON データ) を、jsDelivr (cdn.jsdelivr.net) から 1 日 1 回取得します。
2. Web フォントの読み込み: 設定「Web フォント (Noto Sans JP) を読み込む」が ON の間、Google Fonts (fonts.googleapis.com) にフォントを要求します。このとき、IP アドレスと参照元ページが Google に渡ります。設定で OFF にすると要求しません。
3. 「訳を提案する」: 利用者が自分でこのリンクをクリックしたときだけ、GitHub の Issue フォームが開き、その投稿の URL と未訳タグ名が入力欄に入ります。クリックしない限り何も送られません (送信は GitHub 上で利用者が確定操作をした時のみ)。

エンターテインメント (候補に無い場合は「ツール」)

日本語 (ja)。英語ストアページは任意。

注意: Web Store が受け付けるのは 1 拠点あたり最大 5 枚です。7 枚のうち、list-light / list-dark / show-dark / search / popup-light あたりを選んでください。ポップアップの画像は幅 380 px なので、1280×800 のキャンバスに載せるか、登録時に別途調整が必要です。

## 審査向け注意

- リモートコードの実行はありません。すべての JavaScript は zip に同梱されています。
- 辞書 (jsDelivr から取得) は JSON のデータのみで、コードとして実行・評価しません。
- ホスト権限は sakugabooru.com のみ。jsDelivr への取得は CORS で行うため追加の権限は不要です。
- 本拡張は非公式で、Sakugabooru 運営とは無関係です。
